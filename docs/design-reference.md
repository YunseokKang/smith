# 보고서 디자인 참고 (사용자 제공, 2026-10-05 교체)

사용자가 보고서 디자인 기준으로 제공한 문서의 요약이다. 금융 기관형 마케팅 사이트(Coinbase)의 시각 언어를 묘사한다.
Smith 보고서는 **색·서체 규칙·여백·카드 구성 등 스타일만** 차용하며, 상표·워드마크·전용 서체 이름은 쓰지 않는다.
메일 환경 적용 방식은 `docs/report-design.md` §11을 따른다. (첫 시안인 크림·코랄·세리프 디자인은 사용자가 반려했다.)

## 성격
흰 바탕 위의 조용하고 편집된 지면, 거의 단색. 유일한 강조색은 블루(#0052ff)이며 드물게 쓴다(주요 버튼, 강조 링크).
그 외에는 흰 바탕 + 잉크 + 옅은 회색 밴드 + 아주 어두운 다크 밴드(#0a0b0d)뿐이다. 다크 밴드 위에 한 단계 밝은
카드(#16181c)를 띄우는 구성이 가장 특징적이다. 제목은 가중치 400(굵지 않음)으로 기관의 차분함과 신뢰를 전한다.

## 색
- 강조: 블루 #0052ff, 눌림 #003ecc, 비활성 #a8b8cc. 보조 노랑 #f4b000(장식용, 행동 색 아님).
- 표면: 흰색 #ffffff, 옅은 밴드 #f7f7f7, 회색 칩·보조 버튼 #eef0f3, 다크 #0a0b0d, 다크 카드 #16181c.
- 선: #dee1e6, 옅은 선 #eef0f3.
- 글자: 잉크 #0a0b0d, 본문 #5b616e(약간 차가운 회색), 흐림 #7c828a, 더 흐림 #a8acb3, 다크 위 흰색 #ffffff·흐림 #a8acb3.
- 시장 의미색: 상승 #05b169, 하락 #cf202f — 글자색 전용, 배경 채움 금지.

## 서체
- 제목: 디스플레이 산세리프, 가중치 400, 음의 자간(-0.5 ~ -2px). 본문 산세리프 400/600. 대체: Inter.
- 숫자: 모든 숫자(가격·변화율·표 숫자)는 고정폭 서체(대체: JetBrains Mono, Geist Mono) 500.
- 크기 예: 섹션 제목 36~52px(메일에서는 축소), 카드 제목 18px/600, 본문 16px/400(줄간격 1.5), 배지 12px/600.

## 배치·형태
- 간격 4px 단위, 밴드 사이 넉넉하게(웹 96px), 카드 안 여백 32px.
- 모서리: 카드 24px, 중형 카드 16px, 입력 12px, 버튼·배지 알약형(100px), 아이콘 원형. 각진 모서리 없음.
- 그림자는 한 단계만(거의 쓰지 않음), 흰 바탕 카드는 1px 선.
- 리듬: 흰 편집 밴드 ↔ 옅은 회색 밴드 ↔ 다크 히어로 밴드(위에 다크 카드)를 번갈아 쓴다.

## 할 것 / 하지 않을 것
- 블루는 드물게(밴드당 한두 번). 제목은 굵게 하지 않는다. 숫자는 고정폭. 다크/라이트 밴드를 번갈아 쓴다.
- 두 번째 브랜드 색을 들이지 않는다. 상승·하락 색은 의미 전용이며 버튼 배경으로 쓰지 않는다. 그림자를 겹쳐 쓰지 않는다.

(원문 전체는 2026-10-05 대화에서 사용자가 제공했다. 메일 보고서에 해당하는 부분만 남겼다.)
